# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately to the maintainer via GitHub security advisories.
Do not open public issues for security problems.

## Signing keys

The committed sample pack is signed with a clearly labeled demo key. Production
runs use keyless signing (CI) or an ephemeral local key when `cosign` is present.

## Disclosure

Accepted vulnerabilities are published after a fix ships, following the
coordinated-disclosure window agreed with the reporter.
